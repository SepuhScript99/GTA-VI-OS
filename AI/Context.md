# Vice OS Context

Version: 1.0

---

# Project

Vice OS is a Debian-based Linux distribution focused on professional engineering practices.

The repository is expected to evolve for years and may eventually contain hundreds or thousands of source files.

Architecture should evolve gradually while preserving compatibility whenever practical.

---

# Development Philosophy

The repository is a long-term engineering project.

Every implementation should improve the repository rather than merely adding features.

The project values

- Maintainability
- Reliability
- Documentation
- Testing
- Validation
- Recovery
- Scalability

---

# Repository Source of Truth

Before making decisions always inspect

README.md

PROJECT_STATUS.md

ROADMAP.md

TODO.md

ARCHITECTURE.md

Current source code

Never rely on assumptions.

# Repository Evolution

Do not redesign the repository without strong engineering justification.

Prefer incremental improvement.

Large refactors should be well documented.

---

# Long-Term Expectations

Assume

- Multiple contributors
- Multiple AI models
- Several years of development
- Continuous releases

Design accordingly.
